## Report conflicts

All of these are unresolved. v0 does not pick a winner.

1. **50-question score.** The synthesis pilot says 35/50 then 42/50, with Qwen writing 15 answers. The full-coverage release report says 50/50 on the router path and 50/50 live Qwen. The holdout runner reuses a previous all-pass file unless `FORCE_GOLDEN_50_RERUN=true`, and it sets synthesis off for that golden path.
2. **122-case live model.** The release report says 122/122 live Qwen at 100%, 61/61 in each country. The runner marks 16 indexes as live and enables synthesis on two indexes. The saved results have `live_qwen: true` on 16 rows, and every outcome is `answer` (no clarify, refuse, or no-data).
3. **Certification denominator.** `coverage_manifest_v1.json` has 36 `CERTIFIED` cells, including Coding, Marketing, Pharmacy, Pre-Approvals, and shared Finance and RCM. `RELEASE_MANIFEST.md` says only Inbound, Outbound, and Support Positions are fully certified, with four partial and eleven unverified. The roadmap already flags `catalog.py` for marking gates true without versioned evidence.
4. **The release report's own country table does not match its manifest.** The report's Egypt Employee row says 10 cells and then lists more team names than that. The JSON has 12 certified Egypt Employee teams plus one verified-no-data team (Pre-Approvals IP Offshore). The report's UAE Employee row says 11 certified teams. The JSON has 14 certified UAE Employee teams. Verified-no-data is 5 cells in the JSON and is described as 9 teams in the report. `NOT_APPLICABLE` is 55 cells, mostly Managerial and Corporate, which is not the same thing as the 6 inactive legacy team rows.
5. **Pre-Approvals names.** The manifest uses `Pre-Approvals OP Dubai`, `Pre-Approvals OP Final SHJAJM`, `Pre-Approvals IP Final Dubai`, `Pre-Approvals IP Final SHJAJM`, `Pre-Approvals IP Elective Dubai`, plus parent rows, and sets their function to `RCM`. The conversation release manifest lists `Pre-Approvals OP Dubai`, `IP Initial Dubai`, `IP Final Dubai`, `OP Sharjah`, and `OP Ajman`. The 122-case results use short labels such as `OP Dubai` and `IP Sharjah`. v0 does not choose a canonical UAE name; `fz-043` leaves that binding `PENDING`.
6. **English-question counts, three ways.** The fixture header says 132 and the array has 130, split 59 / 23 / 48 across 64 groups. The classifier report says 126 questions, 61 groups, split 57 / 22 / 47. The benchmark JSON says 59 / 24 / 49 and its limitations paragraph says 132 questions. The conversation release manifest says 130 after dropping two duplicate ids, split 59 / 23 / 48, which matches the array and not the benchmark file.
7. **Provider calls.** The classifier report says the hybrid router made 0 provider calls and a 0% reduction. The benchmark JSON records hybrid provider calls of 3, 2, and 3 on the three splits and a negative reduction. The release-manifest table again says 0 hybrid provider calls.
8. **Dialogue count.** The script contains 25 cases. The release manifest says 26/26.
9. **v2 "families" arithmetic.** The release manifest's opening paragraph puts 1/1, 5/5, and 19/19 inside a "15 families" clause. Those add to 25 scenarios. The group counts in the same manifest and in the benchmark JSON are 1, 2, and 12 families. The file on disk matches the group counts.
10. **Latency, both labeled as about 200 employees.** The full-coverage report says a scoped DB read at p50 44.13 ms and p95 62.91 ms, and a compound Qwen turn at p50 8.08 s and p95 8.41 s. The conversation release manifest's `certify_scopes_and_benchmark.py` table says routine-local cold p95 211.50 ms and warm p95 240.13 ms. The golden summary inside the phase 6 JSON also quotes a direct p50 of 6.214 s and p95 of 12.51 s, while many per-question `elapsed_s` values in that same golden list are near 0. These are not one measurement.
11. **Explorer sample.** The frozen phase 0 sample and its reproduction are 0/10 `passed_basic`. The phase 4 file and the release report say 10/10. The pilot note says basic checks are not semantic certification.
12. **Shared All versus a country total.** The manifest text for Finance and RCM says region `All` is excluded from a strict single-country total unless attribution is verified. The release report still counts those two employee cells as certified shared scope. No signed attribution rule is in the question fixtures. v0 asks instead of assuming (`fz-035`, `ho-058`).

## What v0 reused

Question wording was reused where the information need belongs in one of the new groups. The reuse is on `provenance.reused_question_from`. Thirteen frozen cases and thirty-three held-out cases point at an older file. Expected numbers, people, and headlines from those files were not copied. October 2026 as an "unavailable" golden result (`golden_50_results` id 38) was not promoted, because that label came from the system run rather than a signed publication calendar. December 2030 was kept only as a calendar bound after the 9 Nov 2026 baseline (`ho-046`).
